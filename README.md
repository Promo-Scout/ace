# ACE Money Transfer Promo Codes — GitHub Pages

**Website:** https://promo-scout.github.io/ace/

## Flat-root repository

All files are in the **repository root**. No `guides/`, `assets/`, or `scripts/` directories are required.

- `index.html` — main landing page with ACE banner, referral code and country cards.
- `ace-money-transfer-<country>.html` — country guide pages at root URLs.
- Other `.html` pages — additional transfer/referral guides.
- `style.css` — shared stylesheet; HTML also contains embedded CSS as a fallback.
- `sitemap.xml`, `robots.txt`, `.nojekyll` — GitHub Pages/SEO support.

## Publishing

1. Unzip and upload **all files directly into the repository root** of `promo-scout/ace`.
2. Delete old folders `guides/`, `assets/`, `scripts/` from GitHub if they still exist, to prevent duplicate URLs.
3. In Settings → Pages choose `main` and `/ (root)`.
4. After deployment, check https://promo-scout.github.io/ace/ace-money-transfer-nigeria.html
